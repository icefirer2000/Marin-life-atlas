# 海错图 Marine Life Atlas

一个面向海洋生物与环境数据展示的 Three.js 三维地球项目。

**当前版本：v1.9**

项目以可旋转、可缩放的三维地球为基础，将大陆、地理坐标、按需地形和鱼类图鉴组织为可独立控制的图层，便于后续接入真实海洋生态数据。

## 当前功能

- 三维地球：围绕球心旋转、滚轮缩放、自动旋转、暂停和视角复位。
- 地理参考：真实球面经纬线，以及鼠标位置的度分秒和十进制度坐标。
- 大陆图层：内嵌 Natural Earth GeoJSON，显示全球大陆底图、大陆名称，并支持大陆表面点击交互。
- 地形图层：点击大陆后按需加载 DEM，使用海拔分级色彩，并可独立显示等高线。
- 鱼类图鉴：内置 5 个代表性鱼类档案，支持鱼类节点、名称、年份筛选和点击查看图鉴。
- 分布轨迹：可分别选择轨迹起点与终点年份，以年度栖息地节点和箭头显示变化方向。
- 图层控制：大陆底图、大陆名称、经纬度网格、鱼类图鉴、鱼类节点、鱼类名称、分布轨迹、DEM 和等高线均可独立控制。

## 数据说明

当前鱼类档案与年度节点是用于验证交互流程的内置代表性数据，不应解释为真实个体追踪结果。当前轨迹是基于年度节点的展示性路径，并使用几何启发式绕开大陆，不代表真实海流或洄游路线。

后续可接入 OBIS、GBIF、NOAA DisMAP、ICES DATRAS、遥测数据或海洋环境栅格，将内置数据替换为可追溯的物种分布与迁徙数据。

地理数据来源和许可说明见 [`DATA_SOURCES.md`](DATA_SOURCES.md)。

## 运行方式

### 直接查看

双击 `直接运行.html`。该文件内嵌大陆 GeoJSON，基础大陆显示不需要额外地理数据请求；Three.js 通过 CDN 加载，DEM 地形仍需要网络连接。

### Vite 开发模式

建议使用 Node.js 18 或更高版本。在项目根目录执行：

```powershell
npm install
npm run dev
```

然后打开终端显示的本地地址，通常是 `http://localhost:5173/`。

### 生产构建

```powershell
npm run build
npm run build:standalone
```

`npm run build` 输出到 `dist`；`npm run build:standalone` 重新生成可直接打开的 `直接运行.html`。

## 日常开发建议

```powershell
git switch main
git pull --ff-only
git switch -c develop/vX.Y
```

每完成一个可验证的功能或修复，就创建一次清晰的提交；稳定版本完成构建和交互验证后，再合并到 `main` 并创建版本标签。

不要提交 `node_modules`、`dist`、`.vite` 等生成目录。只有在对外交付或离线归档时，才生成完整单文件或压缩包。
