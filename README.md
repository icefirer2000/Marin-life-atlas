# Three.js 三维地球

这是一个 Three.js + Vite 示例，包含：

- 始终围绕球心旋转和缩放
- 无贴图的纯色海洋球体
- 固定在世界坐标中的太阳光和辅助环境光
- 自动旋转与视角复位
- Raycaster 球面拾取及度分秒、十进制度坐标显示
- 由内嵌 Natural Earth 数据实时生成的全球大陆底图
- 10° 间隔真实球面经纬网、大气层和星空背景
- 可扩展的右侧图层控制面板
- 大陆名称、鱼类节点、鱼类名称和分布轨迹独立图层开关
- 内置鱼类图鉴、年度出现节点、年份筛选和独立起止年份轨迹
- 点击大陆后按需加载 z5 Terrarium DEM 球面地形
- DEM 海拔分级色彩与 200–5000 米等高线

## 网络要求

- `直接运行.html` 已内嵌大陆 GeoJSON，但 Three.js 仍由 CDN 加载。
- 基础大陆底图不需要额外网络请求。
- v1.8 起鱼类图鉴使用内置代表性年度节点，不需要额外网络请求。
- v1.6 起的 DEM 地形在点击大陆后从 AWS Open Data 按需加载，因此需要网络连接。
- 每次仅保留当前所选大陆的地形和等高线，以控制内存与显存占用。
- 大陆悬停高亮、点击交互、名称标签和基本信息面板仍基于 GeoJSON 多边形判断。
- 鱼类轨迹当前表达“年度栖息地节点变化线”，不等同于真实个体迁徙路线；v1.9 的避陆箭头轨迹是几何展示启发式，接入遥测数据后可升级为真实迁徙路线。

版本开发记录见 `CHANGELOG.md`。
地理数据来源见 `DATA_SOURCES.md`。

## 无需安装，直接查看

双击 `直接运行.html`。该文件内嵌 Natural Earth 数据；基础大陆显示可离线使用，但 Three.js 仍从 CDN 加载，因此默认需要联网。

## Vite 方式运行

安装 Node.js 后，在本目录打开 PowerShell：

```powershell
npm install
npm run dev
```

然后打开终端显示的本地地址，通常为：

```text
http://localhost:5173/
```

停止服务器时按 `Ctrl+C`。

## 构建

```powershell
npm run build
```

构建结果位于 `dist` 目录。
